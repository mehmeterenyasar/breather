# Microsoft Edge Add-ons — Türkçe

Metinler Chrome listesiyle aynıdır: **[chrome-tr.md](chrome-tr.md)** dosyasındaki
ad, kısa açıklama ve uzun açıklamayı olduğu gibi kullan. Aşağıda yalnızca Edge'e
özgü alanlar var.

## Paket

`.output/breather-<sürüm>-edge.zip`

Edge paketi Chrome paketiyle aynı MV3 derlemesidir; ayrı bir kod yolu yoktur.

## Edge'e özgü alanlar

### Mağaza adı

```
Breather — Odak zamanlayıcı ve mola asistanı
```

### Kısa açıklama (Edge en fazla 200 karakter kabul eder)

```
Pomodoro, kronometre ve sağlık molaları tek yerde. Göz, nefes, duruş ve su molalarını kendi ritmine göre ayarla. Hesap yok, reklam yok; tüm veri cihazında kalır.
```

### Arama anahtar sözcükleri (en fazla 7)

```
pomodoro
odak zamanlayıcı
mola hatırlatıcı
göz molası
nefes egzersizi
verimlilik
kronometre
```
